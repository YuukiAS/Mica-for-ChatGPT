# Branding

## 基本信息

- 正式名称：Mica for ChatGPT
- 当前 tagline：`A lighter, cleaner, less frustrating ChatGPT.`

## 视觉概念

Mica 是覆盖在原生 ChatGPT 之上的增强层，而不是 ChatGPT 的替代品。当前视觉方向强调多层、轻薄、半透明的界面质感，表达“在原生体验之上降低阻力”的产品定位。

当前主色方向：

- ivory
- cool gray
- graphite
- 少量 cyan / blue / violet

## Extension Icon 注意事项

后续真正发布 Chrome extension 前，需要单独制作纯图标版本，至少准备：

- 16×16
- 32×32
- 48×48
- 128×128
- 512×512 source

真正的 extension icon 应只保留中央 Mica symbol，不包含文字、功能卡片或背景 UI。

Chrome 实际使用的图标之后再放到 extension 对应的 icons 目录。不要现在从 16:9 概念图直接裁切凑数。
