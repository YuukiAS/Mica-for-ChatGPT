# Mica 0.5.16 候选只读复核

## 结论

提交 `592221a41eb38f11467b3a112eea739e25a85ff7` 已把 0.5.16 推进到本地自动化和隔离浏览器能够覆盖的边界。正式 Manifest V3 构建、实际扩展页面、三页 PDF、Low Memory 生命周期与 A/B/C 压力测试、键盘焦点、视觉基准和验收控制集均通过。复核没有发现仍可在本地修复的 P0/P1/P2 问题；剩余核心证据需要真实登录态 ChatGPT 或目标物理低内存设备。

这份报告由当前实现线程在提交冻结后完成，不是独立外部审阅。若冻结 Goal 对“独立审阅者”作严格身份要求，该项仍需另行执行；本报告不会把当前线程的复核冒充独立结论。

## 本轮发现与修复

视觉复核发现 1 个 P1 可访问性缺陷：popup 和 Options 都把原生表单控件缩成 1×1 px 并设为透明，但可见的开关轨道和文件导入按钮没有接收键盘焦点轮廓。现已为 popup 的 `.switch-track` 增加 `:focus-visible` 代理，为 Options 的 `.file-button` 增加 `:focus-within` 代理。

真实安装扩展测试不再只统计可访问名称。它会实际聚焦 `#enabled` 与 `#import-highlights`，读取可见代理的计算样式，并要求焦点轮廓至少为 2 px。Validator 1.22.0 同时加入 `installed-extension-focus-proxy-missing-rehash`，证明伪造或缺失这两项证据的候选会被拒绝。

本轮还重新绑定了 0.5.16 的 Low Memory 压力证据，避免旧版本数据通过候选门槛。B/C 的完整扩展运行时均报告 0.5.16；开启 Low Memory 后，重内容保留量由 100 MiB 降至 5 MiB，JavaScript heap 中位数由 101.858 MiB 降至 6.591 MiB，mapping nodes 由 801 降至 41。
