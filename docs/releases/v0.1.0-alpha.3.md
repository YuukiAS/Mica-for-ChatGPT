# Mica for ChatGPT v0.1.0-alpha.3

Alpha / diagnostic UI polish build for Chrome and Edge Chromium.

## What Changed

- Replaces the persistent full-width page badge with a compact Mica status indicator.
- Full status expands temporarily on first initialization, relevant status changes, `Active`, `Degraded`, or user click, then returns to compact mode.
- Adds composer-aware overlay placement so the status indicator avoids ChatGPT's bottom composer, send controls, and narrow split-view layouts.
- Adds a local, non-blocking toast after Mica successfully dismisses the known allowlisted ChatGPT notice.
- Repeated known-dismiss events merge into the same toast instead of stacking.

## Reliability Boundary

- The only auto-dismiss rule remains `chatgpt.rate_limit_history_ack.zh-CN.v1`.
- No new auto-confirm rules were added.
- Mica does not retry, reload, resend requests, switch conversations, bypass rate limits, or click unknown/consequential dialogs.

## Diagnostics

- Existing runtime diagnostics remain available in the popup.
- Reports now include lightweight overlay state: current placement, compact/expanded mode, toast visibility, and toast count.
- Diagnostics remain local only and do not include conversation text, attachment content, dialog HTML, or telemetry upload.

## Current Findings

- Current ChatGPT already appears to natively virtualize long conversations: real logged-in Edge testing observed about 5-9 mounted turns while scrolling through a much longer thread.
- Mica's containment optimization remains a fallback, not a proven fix for current real long-thread performance.
- Final P0 performance validation on the 8 GB MacBook Neo is not complete.

## Install

Download and unzip `mica-for-chatgpt-v0.1.0-alpha.3.zip`, then use Chrome / Edge `Load unpacked` on the extracted directory. The extracted directory should directly contain `manifest.json`.

## Not Included

- Markdown Copy.
- Retry automation.
- New automatic dialog rules.
- GitHub Actions publishing.
