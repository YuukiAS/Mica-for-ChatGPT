# Mica for ChatGPT v0.1.0-alpha.2

Alpha / diagnostic build for Chrome and Edge Chromium.

## What This Build Is For

- Local runtime diagnostics for real long ChatGPT threads.
- Verifying current mounted conversation turn behavior on real devices.
- Keeping the existing low-risk `content-visibility` containment path as a fallback when Mica actually has extra offscreen mounted turns to optimize.
- Reducing one known, safe ChatGPT acknowledgement interruption without retrying or bypassing rate limits.

## Current Findings

- Current ChatGPT already appears to natively virtualize long conversations: real logged-in Edge testing observed about 5-9 mounted turns while scrolling through a much longer thread.
- Mica no longer reports mounted DOM turns as if they were the full conversation length.
- Status uses mounted semantics, for example `Mica · Native virtualization · 9 mounted`.
- Mica's containment optimization remains a fallback, not a proven fix for current real long-thread performance.

## Reliability

- Adds `Auto-dismiss known interruptions`, enabled by default.
- The only current rule is `chatgpt.rate_limit_history_ack.zh-CN.v1`.
- It only dismisses the known Chinese ChatGPT acknowledgement dialog for temporary conversation-history access rate limiting.
- It does not retry, reload, resend requests, switch conversations, bypass server limits, or click unknown/consequential dialogs.
- Diagnostics count dismissals by rule ID only; no dialog HTML, conversation text, attachment content, or telemetry is collected.

## Privacy

- Runs locally in the browser.
- No telemetry upload.
- Diagnostics do not copy conversation text or attachment content.
- No additional host permission beyond ChatGPT hosts.

## Known Limits

- This is not a stable release.
- Final P0 performance validation on the 8 GB MacBook Neo is not complete.
- Markdown Copy, Retry, and other Phase 2 features are not included.

## Install

Download and unzip `mica-for-chatgpt-v0.1.0-alpha.2.zip`, then use Chrome / Edge `Load unpacked` on the extracted directory. The extracted directory should directly contain `manifest.json`.
