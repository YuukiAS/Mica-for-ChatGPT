# Mica for ChatGPT 0.5.16 预发布说明

> 当前状态：本地预发布候选，尚未创建 GitHub Release，也未合入 `main`。源码、开发构建、隔离浏览器回归、压力证据和本地安装包已经收口；真实登录态 ChatGPT 与目标物理低内存设备仍需最后一次集中人工确认。确认前不得标成稳定版。

0.5.16 把复制、高亮、PDF 导出和 Low Memory 保留在同一份正式扩展构建中，并补齐 popup 开关与 Options 文件导入控件的键盘焦点可见性。用户可以通过固定路径 `dist/mica-dev` 加载候选；完成最后的人工边界验收后，再从最终合入提交生成正式预发布资产。

## 本版包含

### 单回答复制

- 在无法证明 ChatGPT 原生回答操作区位置时，使用浏览器右键菜单提供安全入口。
- 右键目标必须能唯一解析为一条已经生成完毕的 assistant 回答；结构不明确时不执行。
- Markdown 输出保留标题、列表、引用、表格、代码、链接、行内代码以及行内和展示公式。
- 复制、Notion 富文本和 PDF 共用 `AnswerDocument`，没有新增第二套页面抓取逻辑。

### ChatGPT 高亮与 PDF

- 支持 4 种颜色、换色、删除和清理当前回答的全部高亮。
- 支持正文、行内公式和展示公式选区；刷新、重新挂载和等价数学重排后会尝试恢复。
- 重复文本、分支变化或锚点不唯一时默认不附着，也不会在 PDF 中猜测旧锚点。
- PDF 从 `AnswerDocument` 和同一份高亮记录生成，保留可搜索、可选择的中文、英文、表格、代码和数学文字层。
- 实际三页 PDF 同时证明 1 个当前高亮可解析、1 个内容变化前的旧锚点保持 unresolved。

### Low Memory

- 在 ChatGPT 解码和渲染超长 conversation 前，把客户端历史限制为最近 40 个可见 turns，并保留必要的 system、tool 和 branch 依赖。
- `Load full history` 可临时恢复完整历史；关闭功能或移除扩展后，刷新页面即可回到原生历史。
- 不修改服务器历史。遇到未知数据结构时保持原样并安全退出。

### 键盘可访问性

- popup 的透明原生复选框聚焦后，会在可见开关轨道上显示焦点轮廓。
- Options 的透明文件输入聚焦后，会在可见导入按钮上显示焦点轮廓。
- 真实安装扩展测试读取计算样式，要求两处焦点轮廓都至少为 2 px；只统计标签数量不再算通过。

## 本地验证

正式 `dist/mica-dev` 已作为 Manifest V3 扩展安装到隔离 Chromium，覆盖 content scripts、Service Worker、storage、动态注册、右键菜单、可信鼠标与剪贴板操作、popup、Options、PDF 页面、Low Memory 生命周期和 Worker 重启。测试期间没有访问真实 ChatGPT，也没有产生真实 ChatGPT 请求。

- `npm test`：通过；其中一次早期运行正确拒绝了尚未同步的旧版收敛矩阵，修正文档版本后通过。
- `npm run test:e2e`：最终候选运行 1 次并通过。
- 视觉基准：Chromium 151 下人工复核并冻结 6 张 0.5.16 基准图，自动比较为 `MATCH`。
- PDF：实际生成 3 页文件，PDF.js 指针选择、独立文字提取和高亮继承通过。
- Low Memory A/B/C：三组各 3 个样本；B/C 均加载 0.5.16 完整扩展能力。开启后重内容保留量由 100 MiB 降至 5 MiB，JavaScript heap 中位数由 101.858 MiB 降至 6.591 MiB，mapping nodes 由 801 降至 41。
- Acceptance validator 1.22.0：14/14 正确控制样本接受，65/65 错误控制样本拒绝；缺失焦点代理、过期 Low Memory 运行时、Worker 绕过、PDF 丢高亮和伪造视觉基线都会被拒绝。
- Stress：本轮未重复运行。改动只涉及扩展 UI 的焦点样式与相应测试门控，没有触及 composer、observer、Low Memory 或 Highlighter 生命周期；已有 8 轮压力证据继续保留。

## 安装候选

开发候选使用固定路径：

```text
D:\Code\Mica-for-ChatGPT\dist\mica-dev
```

在 Chrome 或 Edge 的扩展管理页开启 Developer mode，选择 Load unpacked 并加载该目录。后续更新只需重新构建后点击 Reload。
