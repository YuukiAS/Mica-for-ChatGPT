# Mica for ChatGPT 0.5.15 预发布说明

> 当前状态：预发布候选，尚未创建 GitHub Release。候选已经通过本地完整验收，仍需一次登录态 ChatGPT 和目标设备集中确认。确认前不得标成稳定版。

0.5.15 把复制、高亮、PDF 导出和 Low Memory 接入同一份正式扩展构建，并修复列表高亮投影与 PDF 文本层分隔符不一致的问题。用户可以先通过固定开发路径 `dist/mica-dev` 加载候选；完成最后一次人工确认后，将提供版本化 ZIP 和 SHA-256。

## 本版包含

### 单回答复制

- 在无法证明 ChatGPT 原生回答操作区位置时，使用浏览器右键菜单提供安全入口。
- 右键目标必须能唯一解析为一条已经生成完毕的 assistant 回答；结构不明确时不执行。
- Markdown 输出保留标题、列表、引用、表格、代码、链接、行内代码以及行内和展示公式。
- 复制、Notion 富文本和 PDF 共用 `AnswerDocument`，没有新增第二套页面抓取逻辑。

### ChatGPT 高亮

- 支持 4 种颜色、换色、删除和清理当前回答的全部高亮。
- 支持正文、行内公式和展示公式选区。
- 页面刷新、回答重新挂载和数学节点重新排版后会尝试恢复；重复文本、分支变化或锚点不唯一时默认不附着。
- 默认颜色和快捷键由统一设置控制。

### PDF 导出

- 从 `AnswerDocument` 和同一份高亮记录生成，不使用整页截图。
- 保留可搜索、可选择的文字层，覆盖中文、英文、表格、代码、链接、行内公式和展示公式。
- 已验证跨正文与公式的指针选择、展示公式选择以及网页高亮到 PDF 的继承。
- 公式局部高亮无法可靠映射到 MathML 子树时，会保留可见 TeX 和高亮位置，不冒充完整语义 MathML。

### Low Memory

- 在 ChatGPT 解码和渲染超长 conversation 前，把客户端历史限制为最近 40 个可见 turns，并保留必要的 system、tool 和 branch 依赖。
- `Load full history` 可临时恢复完整历史；关闭功能或移除扩展后，刷新页面即可回到原生历史。
- 不修改服务器历史。遇到未知数据结构时保持原样并安全退出。

## 验证范围

正式 `dist/mica-dev` 已作为 Manifest V3 扩展安装到隔离 Chromium，覆盖 content scripts、Service Worker、storage、动态注册、右键菜单、可信鼠标与剪贴板操作、popup、Options、PDF 页面、Low Memory 生命周期和 Worker 重启。测试期间没有访问真实 ChatGPT，也没有产生外部请求。

- `npm test`：通过。
- 完整扩展 E2E：通过；最终候选只运行 1 次完整 Tier 2。
- E2E 压力测试：8 轮、40 次运行全部通过。
- Highlighter 压力测试：8/8 通过。
- 视觉基准：320、368、400 px 与明暗主题共 6 张基准图通过。
- PDF：实际生成 3 页文件，PDF.js 指针选择和文字层检查通过。
- Low Memory A/B/C：开启后重内容保留量由 100 MiB 降至 5 MiB，JavaScript heap 中位数由约 101.9 MiB 降至约 6.6 MiB。
- Acceptance validator 1.20.0：14/14 正确控制样本接受，63/63 错误控制样本拒绝；完整扩展生成的 PDF 必须包含当前可解析的高亮，并把内容变化前的旧锚点保持为 unresolved。最终 `functional-convergence` 候选 20/20 gate 通过。

## 已知边界

- 当前登录态 ChatGPT 的原生回答操作区位置仍未取得足够证据，因此使用右键菜单，不猜测插入按钮。
- 登录态页面中的选区、重新挂载、完整历史恢复和系统剪贴板仍需最后一次人工确认。
- Low Memory 的自动压力证据来自受限目标环境，不代表目标物理低内存设备已经验收。
- 真实 ChatGPT 原生 Stop、assistant retry、确认未提交后的 resend、Connector 历史故障和 suggested work 仍保持 fail-open，不属于本次 4 项核心能力的发布主张。
- Notion 原生可编辑公式和通用网页高亮不属于本轮预发布范围。

## 安装候选

开发候选使用固定路径：

```text
D:\Code\Mica-for-ChatGPT\dist\mica-dev
```

在 Chrome 或 Edge 的扩展管理页开启 Developer mode，选择 Load unpacked 并加载该目录。后续更新只需重新构建后点击 Reload。
